边界：

- 网站是独立项目，未经我确认不能修改掌柜智库业务代码、提交或推送 GitHub、发布到公网。
- 优先复用 Python 与原生前端环境；引入框架必须解释具体收益，不要为改造而改造。
- 所有 AST/AI 推断的调用、数据流、条件分支都必须标注 pending / 待验证。
- confirmed 只用于能直接从源码定位的显式结构、导入和流程配置；运行成功需要独立的运行时证据。
- 每条代码关系保存文件路径、1-based 行号、符号（适用时）与文件 SHA-256。来源变化时不能继续暗示证据仍有效。
- 不执行 app，不连接业务数据库，不读取或输出 .env、密钥、真实聊天数据。
- 不直接手工改自动生成的 graph.json；修改提取规则再重新生成。人工学习内容维护在 content/learning.json。
